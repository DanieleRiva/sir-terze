## Prova subito

Questo è un **automa a stati finiti**: riconosce le stringhe binarie che **finiscono con `01`**. Scrivi una stringa di `0` e `1` e premi **Passo ▶** per seguirlo simbolo per simbolo.

<Automa
	states={[
		{ id: 'q0', x: 80, y: 100, initial: true },
		{ id: 'q1', x: 240, y: 100 },
		{ id: 'q2', x: 400, y: 100, final: true },
	]}
	transitions={[
		{ from: 'q0', to: 'q0', label: '1' },
		{ from: 'q0', to: 'q1', label: '0' },
		{ from: 'q1', to: 'q1', label: '0' },
		{ from: 'q1', to: 'q2', label: '1' },
		{ from: 'q2', to: 'q1', label: '0' },
		{ from: 'q2', to: 'q0', label: '1', bend: 45 },
	]}
	simula="1101"
/>
