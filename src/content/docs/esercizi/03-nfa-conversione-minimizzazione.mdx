### Esercizio 2 · Simulazione con gli insiemi

Simulare l'NFA dell'esercizio 1 sulla stringa `aabba`, scrivendo l'insieme degli stati attivi dopo ogni simbolo. La stringa è accettata?

<details>
<summary>Soluzione</summary>

| Dopo | Stati attivi |
| :-- | :-- |
| inizio | &#123;q₀&#125; |
| `a` | &#123;q₀, q₁&#125; |
| `a` | &#123;q₀, q₁&#125; |
| `b` | &#123;q₀, q₂&#125; |
| `b` | &#123;q₀, q₃&#125; |
| `a` | &#123;q₀, q₁, q₃&#125; |

L'insieme finale contiene q₃, che è finale: **accettata**.

</details>

### Esercizio 3 · Costruzione per sottoinsiemi

Trasformare l'NFA dell'esercizio 1 in un DFA con la costruzione per sottoinsiemi. Quanti stati ha il DFA?

<details>
<summary>Soluzione</summary>

| Nome | Insieme | con `a` | con `b` | Finale? |
| :-: | :-- | :-: | :-: | :-: |
| → A | &#123;q₀&#125; | B | A | |
| B | &#123;q₀, q₁&#125; | B | C | |
| C | &#123;q₀, q₂&#125; | B | D | |
| D | &#123;q₀, q₃&#125; | E | D | ✓ |
| E | &#123;q₀, q₁, q₃&#125; | E | G | ✓ |
| G | &#123;q₀, q₂, q₃&#125; | E | D | ✓ |

Calcolo di una riga, per esempio G = &#123;q₀, q₂, q₃&#125; con `b`: q₀ → &#123;q₀&#125;, q₂ → &#123;q₃&#125;, q₃ → &#123;q₃&#125;; unione &#123;q₀, q₃&#125; = D.

Il DFA ha **6 stati**, di cui 3 finali (quelli che contengono q₃).

</details>

### Esercizio 4 · ε-chiusura

Dato l'ε-NFA qui sotto, calcolare ECLOSE di ciascuno stato e l'insieme degli stati attivi dopo aver letto `a`.

<Automa

		{ id: '2', x: 210, y: 50 },
		{ id: '3', x: 350, y: 110 },
		{ id: '4', x: 210, y: 200, final: true },
	]}
	transitions={[
		{ from: '1', to: '2', label: 'ε' },
		{ from: '2', to: '3', label: 'ε' },
		{ from: '1', to: '4', label: 'a' },
		{ from: '3', to: '4', label: 'b' },
		{ from: '4', to: '1', label: 'ε' },
	]}
/>

<details>
<summary>Soluzione</summary>

- ECLOSE(1) = &#123;1, 2, 3&#125; (1 → 2 con ε, poi 2 → 3 con ε)
- ECLOSE(2) = &#123;2, 3&#125;
- ECLOSE(3) = &#123;3&#125;
- ECLOSE(4) = &#123;4, 1, 2, 3&#125; (4 → 1, poi 1 → 2 → 3)

Simulazione: all'inizio gli stati attivi sono ECLOSE(1) = &#123;1, 2, 3&#125;. Con `a`: solo 1 ha una transizione con `a`, verso 4. Poi ε-chiusura: ECLOSE(4) = **&#123;1, 2, 3, 4&#125;**, che contiene lo stato finale 4.

</details>

### Esercizio 6 · Minimizzazione

Minimizzare il DFA a 6 stati ottenuto nell'esercizio 3.

<details>
<summary>Soluzione</summary>

Tutti gli stati sono raggiungibili.

**Giro 0:** non finali &#123;A, B, C&#125;, finali &#123;D, E, G&#125;.

**Giro 1:**
- &#123;A, B, C&#125; con `a` vanno tutti in B (non finali); con `b`: A → A (non finale), B → C (non finale), C → D (finale). Si divide: &#123;A, B&#125; e &#123;C&#125;.
- &#123;D, E, G&#125;: con `a` vanno tutti in E, con `b` vanno in D, G, D: tutti finali. Non si divide.

**Giro 2:**
- &#123;A, B&#125; con `b`: A → A (gruppo &#123;A, B&#125;), B → C (gruppo &#123;C&#125;). Si divide: &#123;A&#125;, &#123;B&#125;.
- &#123;D, E, G&#125;: ancora tutti nello stesso gruppo. Non si divide.

**Giro 3:** nessuna divisione. Fine.

DFA minimo: **4 stati** A, B, C, e lo stato DEG che riunisce i tre finali.

È esattamente il DFA che si progetterebbe a mano per "contiene `abb`" con il metodo dei [sei passi](/sir-terze/lezioni/02-dfa/03-progettare-un-dfa/).

</details>

### Esercizio 7 · Stati equivalenti

Nel DFA della tabella, quali stati sono equivalenti? Disegnare il DFA minimo e descrivere a parole il linguaggio.

| δ | 0 | 1 |
| :-- | :-: | :-: |
| → A | B | C |
| B | A | D |
| C | D | A |
| \* D | D | D |

<details>
<summary>Soluzione</summary>

**Giro 0:** &#123;A, B, C&#125; e &#123;D&#125;.

**Giro 1:** per ogni stato di &#123;A, B, C&#125; guardiamo in quale gruppo porta ciascun simbolo (N = non finali, F = finali):

| Stato | con `0` | con `1` |
| :-: | :-: | :-: |
| A | B (N) | C (N) |
| B | A (N) | D (F) |
| C | D (F) | A (N) |

I tre stati hanno tre comportamenti diversi: il gruppo si divide in &#123;A&#125;, &#123;B&#125;, &#123;C&#125;.

**Nessuno stato è equivalente**: il DFA è già minimo.

Linguaggio: partendo da A, le coppie `00` e `11` riportano in A, mentre le coppie `01` e `10` portano in D, da cui non si esce più. Quindi una stringa è accettata se, **dividendola in coppie di simboli a partire dall'inizio, almeno una coppia è formata da due simboli diversi**. Per esempio: `0010` è accettata (coppie `00`, `10`); `010` è accettata (la prima coppia è `01`); `1100` è rifiutata (coppie `11`, `00`).
