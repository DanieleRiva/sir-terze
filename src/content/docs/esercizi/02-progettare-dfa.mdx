Esercizi sul capitolo [Automi deterministici](/sir-terze/lezioni/02-dfa/01-definizione-dfa/). Per ognuno: progettare il DFA **su carta** seguendo il [metodo in sei passi](/sir-terze/lezioni/02-dfa/03-progettare-un-dfa/), poi costruirlo in JFLAP e collaudarlo con **Multiple Run**. Le soluzioni contengono un simulatore per confrontare i risultati.

<Aside type="tip">
Dove non è indicato diversamente, l'alfabeto è Σ = &#123;a, b&#125;. Le transizioni che portano allo **stato pozzo** sono disegnate esplicitamente solo dove è utile per capire.
</Aside>

**Legenda della difficoltà:** ⭐ facile · ⭐⭐ media · ⭐⭐⭐ impegnativa

### Esercizio 1 ⭐ · Inizia con `ab`

Costruire un DFA **completo** che accetta le stringhe che iniziano con `ab`.

<details>
<summary>Soluzione</summary>

### Esercizio 5 ⭐⭐ · Non contiene `bb`

Le stringhe in cui non compaiono mai due `b` consecutive.

<details>
<summary>Soluzione</summary>

Trucco utile: si costruisce l'automa che **contiene** `bb` e poi si scambiano finali e non finali (è il complemento). Oppure si ragiona direttamente: devo ricordare se l'ultimo simbolo era `b`, e se ho già visto `bb` (pozzo).

<Automa
	r={24}
	states={[
		{ id: 'A', x: 80, y: 90, initial: true, final: true },
		{ id: 'B', x: 250, y: 90, final: true },
		{ id: 'P', label: 'pozzo', x: 420, y: 90 },
	]}
	transitions={[
		{ from: 'A', to: 'A', label: 'a' },
		{ from: 'A', to: 'B', label: 'b' },
		{ from: 'B', to: 'A', label: 'a' },
		{ from: 'B', to: 'P', label: 'b' },
		{ from: 'P', to: 'P', label: 'a, b' },
	]}
	simula="ababb"
/>

A = "l'ultimo simbolo non è `b`", B = "l'ultimo simbolo è `b`". Entrambi finali: finché non arriva `bb` la stringa va bene.

</details>

### Esercizio 9 ⭐⭐ · Inizia e finisce con lo stesso simbolo

Accettare le stringhe non vuote che iniziano e finiscono con lo stesso simbolo (`a`, `aba`, `bb`, `babb`…).

<details>
<summary>Soluzione</summary>

Il primo simbolo "sceglie un ramo" e da lì non si cambia più; nel ramo si ricorda l'ultimo simbolo.

		{ from: 'A1', to: 'A2', label: 'b' },
		{ from: 'A2', to: 'A2', label: 'b' },

### Esercizio 10 ⭐⭐ · Contiene `ab` ma non `ba`

Suggerimento: provare a scrivere la forma generale delle stringhe accettate.

<details>
<summary>Soluzione</summary>

Se una stringa contiene `ab` ma non `ba`, una volta passati dalle `a` alle `b` non si può più tornare alle `a`. Le stringhe sono quindi della forma **a⁺b⁺** (almeno una `a`, poi almeno una `b`).

<Automa
	r={24}
	states={[
		{ id: 'q0', x: 80, y: 90, initial: true },
		{ id: 'q1', x: 230, y: 90 },
		{ id: 'q2', x: 380, y: 90, final: true },
		{ id: 'P', label: 'pozzo', x: 230, y: 230 },
	]}
	transitions={[
		{ from: 'q0', to: 'q1', label: 'a' },
		{ from: 'q1', to: 'q1', label: 'a' },
		{ from: 'q1', to: 'q2', label: 'b' },
		{ from: 'q2', to: 'q2', label: 'b' },
		{ from: 'q0', to: 'P', label: 'b' },
		{ from: 'q2', to: 'P', label: 'a' },
		{ from: 'P', to: 'P', label: 'a, b', loop: 'bottom' },
	]}
	simula="aabbb"
/>

</details>

### Esercizio 11 ⭐⭐⭐ · Numeri binari multipli di 5

Σ = &#123;0, 1&#125;, lettura dalla cifra più significativa. Suggerimento: rivedere l'[esempio dei multipli di 3](/sir-terze/lezioni/02-dfa/03-progettare-un-dfa/#esempio-3--numeri-binari-divisibili-per-3).

<details>
<summary>Soluzione</summary>

Cinque stati, uno per ogni resto; il nuovo resto è (2·r + c) mod 5.

| δ | 0 | 1 |
| :-- | :-: | :-: |
| → \* R0 | R0 | R1 |
| R1 | R2 | R3 |
| R2 | R4 | R0 |
| R3 | R1 | R2 |
| R4 | R3 | R4 |

<Automa

### Esercizio 12 ⭐⭐⭐ · Intersezione con la costruzione prodotto

Accettare le stringhe con un numero **dispari** di `a` **e** un numero **pari** di `b`.

<details>
<summary>Soluzione</summary>

Due informazioni indipendenti (parità delle `a`, parità delle `b`) → 2 × 2 = 4 stati. Chiamiamo gli stati con due lettere: la prima per le `a`, la seconda per le `b` (P = pari, D = dispari).

<Automa
	r={24}
	states={[
		{ id: 'PP', x: 90, y: 80, initial: true },
		{ id: 'DP', x: 330, y: 80, final: true },
		{ id: 'PD', x: 90, y: 270 },
		{ id: 'DD', x: 330, y: 270 },
	]}
	transitions={[
		{ from: 'PP', to: 'DP', label: 'a' },
		{ from: 'DP', to: 'PP', label: 'a' },
		{ from: 'PD', to: 'DD', label: 'a' },
		{ from: 'DD', to: 'PD', label: 'a' },
		{ from: 'PP', to: 'PD', label: 'b' },
		{ from: 'PD', to: 'PP', label: 'b' },
		{ from: 'DP', to: 'DD', label: 'b' },
		{ from: 'DD', to: 'DP', label: 'b' },
	]}
	simula="abb"
/>

Le `a` muovono in orizzontale, le `b` in verticale. È finale solo DP (a dispari, b pari). Cambiando gli stati finali si ottengono tutte le altre combinazioni: per esempio "numero pari di `a` **oppure** numero pari di `b`" ha finali PP, DP, PD.

</details>
